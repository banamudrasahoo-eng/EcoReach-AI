About EcoReach AI

Project overview, SDG alignment, technology architecture, and strategic roadmap.

📌 Project Overview

Project Name: EcoReach AI

Tagline: An AI-Powered Smart Campus Sustainability Assistant

Internship Program: 1M1B AI for Sustainability Virtual Internship

In Collaboration With: IBM SkillsBuild & AICTE

Primary SDG: SDG 12: Responsible Consumption

Secondary SDGs: SDG 11 SDG 13

Target Users: Students, Faculty, Administrators, Maintenance Teams

💻 Technology Stack & AI Approach

🐍 Backend

Python 3 & Flask framework providing light REST API endpoints and clean modular server logic.

🎨 Frontend

HTML5, CSS3 with eco-themed variables, JavaScript (ES6+), and Chart.js for data visualization.

🤖 Prototype AI Engine

Structured NLP-inspired classification, domain matching rules, prompt workflow parser, and fallback guardrails.

💾 Data Management

In-memory JSON structure with zero complex database setup required for seamless local VS Code execution.

🚀 Future Scope & Upgrade Roadmap

Note: The following features represent planned roadmap enhancements for post-prototype deployment:

🔹 IBM Granite LLM Integration

Connecting the prompt workflow pipeline to IBM Granite via IBM Watsonx API for generative responses.

🔹 RAG Campus Knowledge Base

Retrieval-Augmented Generation using specific campus sustainability policies, handbooks, and schedules.

🔹 Real-Time IoT Sensor Integration

Streaming live electricity meter and smart water valve data directly into the Sustainability Dashboard.

🔹 Computer Vision Waste Scanning

Camera-based image classification to automatically identify trash items at disposal bins.

🔹 Predictive Energy Analytics

Machine learning time-series models to forecast monthly campus utility bills and peak demand spikes.

🔹 Campus Gamification & Leaderboards

Inter-hostel sustainability competitions, eco-badges, and rewards for reduced power consumption.
